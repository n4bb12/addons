# Addons

Installable addons for World of Warcraft 1.12.1 and 1.14.2.

Copy one addon folder into `Interface/AddOns`. The repository root is not an AddOns directory. A release zip is that one folder.

## 1.12.1

- [Extended Character Stats](1.12.1/ExtendedCharacterStats) — extra combat stats beside the character sheet. Interface 11200. A 1.12 port of [Extended Character Stats 5.5.2](https://github.com/BreakBB/ExtendedCharacterStats) by BreakBB and Ethulu. See `README.txt` in the addon.

## 1.14.2

- [Extended Character Stats](1.14.2/ExtendedCharacterStats) — the same addon for interface 11402.
- [Whisper Dash Fix](1.14.2/WhisperDashFix) — drops the empty realm dash the 1.14 client sometimes adds to a whisper name.
